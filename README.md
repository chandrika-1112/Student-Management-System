# Student Management System

## 📌 Project Overview

The Student Management System is a responsive web application developed using HTML, CSS, and JavaScript. It helps users manage student records through a simple and user-friendly interface.

Users can add, view, edit, delete, search, and filter student records. The application uses browser localStorage to save student information so that the data remains available after refreshing the page in the same browser.

## 🎯 Objectives

- To develop a responsive student management website.
- To perform CRUD operations on student records.
- To implement form validation using JavaScript.
- To provide search and filter functionality.
- To practice Git, GitHub, and GitHub Pages deployment.

## ✨ Features

- Add new student records.
- Edit existing student details.
- Delete student records with confirmation.
- Search students by name or student ID.
- Filter students by course and year.
- Validate form inputs.
- Prevent duplicate student IDs and email addresses.
- Save records using browser localStorage.
- Toggle dark mode.
- Export student records to CSV.
- Responsive layout for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
- Git
- GitHub
- GitHub Pages
